## What this project is
HELIOS AIOps: 3-layer ML+LLM pipeline that **detects, classifies, and remediates** Kubernetes incidents
automatically — replaces generic AlertManager with intelligent detection.
Pipeline: **Statistical anomaly (Z-score) → ML XGBoost v7 (52 scenarios) → LLM Qwen 3B F16 (Ollama) → Camunda BPMN remediation → Email notification.**
